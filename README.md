# Concrete Neural Network

## Project Overview
This project explores the application of Artificial Neural Networks (ANN) and machine learning techniques to predict concrete compressive strength.

The project is part of my graduate research in Construction Management at East Carolina University and combines my background in precast concrete quality control with data-driven modeling.

## Research Objectives
- Analyze concrete mixture and strength data
- Prepare and preprocess data for machine learning
- Develop an Artificial Neural Network (ANN)
- Train and evaluate the predictive model
- Explore applications of machine learning in concrete design and quality control
